**Rust 1.97, `wasm32-unknown-unknown`**

- **Default features:** Rust 1.97 uses LLVM 22; Rust 1.95 moved to LLVM 22 and Rust 1.99 to LLVM 23. Its default "generic" CPU enables `mutable-globals` and `sign-ext` (since Rust 1.70), `multivalue` and `reference-types` (since Rust 1.82 / LLVM 19), and `bulk-memory` and `nontrapping-fptoint` (since Rust 1.87 / LLVM 20).
- **No later changes:** The LLVM 21 and 22 release notes list no changes to the generic CPU defaults.
- **SIMD:** `simd128` is not on by default. Turn it on with `RUSTFLAGS="-C target-feature=+simd128"`. It is safe for Safari 16.4 and later. Wasm can't detect features at runtime, so if older browsers matter, ship two binaries and pick one with `wasm-feature-detect`.
- **Turning defaults off:** `-Ctarget-cpu=mvp` plus `-Zbuild-std` (nightly), or the `wasm32v1-none` target for `no_std`.
- **Rust 1.96 change:** rustc no longer passes `--allow-undefined` on wasm targets. Imports must now be declared, for example through wasm-bindgen or `#[link(wasm_import_module)]`.
- **Tooling:** Use a `wasm-opt` version that accepts these features.
